Manual práctico de R

Tu chuleta de funciones, ordenada por paquetes, con ejemplos siempre con las mismas variables.

función() mi_tabla / mi_vector (objeto) "texto" (valor) if / for (palabra clave) # comentario paquete

Variables que se repiten en todos los ejemplos

mi_tabla → un data.frame (tabla de datos).
mi_vector → un vector de números o texto.
columna → el nombre de una columna, ej. "edad".
mi_valor → un único número o texto.
Así, cuando veas mi_tabla en cualquier ejemplo, sabrás que siempre es "la tabla con la que estamos trabajando".

1. Lo básico y archivos (R base)

getwd()
Te dice en qué carpeta está trabajando R ahora mismo.
getwd()
# "C:/Users/tu_usuario/Documents"

Cambia la carpeta de trabajo. Todo lo que leas o guardes irá/vendrá de ahí si no pones ruta completa.

Crea un archivo vacío nuevo (por ejemplo, un .csv o .txt vacío) en la carpeta de trabajo.

Muestra en pantalla el contenido de un objeto. Es lo que R hace "por defecto" cuando escribes un nombre solo, pero print() es útil dentro de funciones, loops, etc.
mi_valor <- 10
print(mi_valor)
# [1] 10

Crear, abrir y cerrar un documento (script)

• Guardar: Ctrl + S (se guarda como .R).
• Cerrar el script: Ctrl + W, o simplemente la "x" de la pestaña.
• Ejecutar una línea: pon el cursor en la línea y pulsa Ctrl + Enter.

5. Crear y explorar tablas (data.frame) (R base)

data.frame()
Crea una tabla nueva a partir de vectores (cada vector es una columna).
mi_tabla <- data.frame(
  nombre = c("Ana", "Luis"),
  edad   = c(25, 30)
)
rbind()
Añade una fila nueva a una tabla (o une dos tablas con las mismas columnas).
mi_tabla <- rbind(mi_tabla, data.frame(nombre = "Marta", edad = 40))
colnames() / rownames()
Muestran o cambian los nombres de columnas / filas.
colnames(mi_tabla)
colnames(mi_tabla) <- c("nombre", "edad_anios")
mi_tabla[fila, columna]
Selecciona partes de la tabla por posición. Si dejas un hueco vacío, coge TODO en esa dimensión.
mi_tabla[1, ]        # fila 1, todas las columnas
mi_tabla[ , 2]       # todas las filas, columna 2
mi_tabla[1, 2]      # fila 1, columna 2
mi_tabla$columna
Accede directamente a una columna por su nombre (devuelve un vector).
mi_tabla$columna
nrow() / ncol() / dim()
Número de filas, columnas, o ambos a la vez.
nrow(mi_tabla)  # nº de filas
ncol(mi_tabla)  # nº de columnas
dim(mi_tabla)   # c(filas, columnas)
names()
Igual que colnames() para data.frames; también funciona con listas.
names(mi_tabla)
unique()
Devuelve los valores distintos de un vector o columna, sin repetir.
unique(mi_tabla$columna)
factor()
Convierte una columna de texto en categorías (útil para variables tipo "sí/no", "bajo/medio/alto"...).
mi_tabla$columna <- factor(mi_tabla$columna)

Extras muy útiles para explorar una tabla

head(mi_tabla)     # primeras 6 filas
tail(mi_tabla)     # últimas 6 filas
str(mi_tabla)      # estructura: tipos de cada columna
summary(mi_tabla)  # resumen estadístico rápido
View(mi_tabla)     # abre la tabla en una pestaña visual

6. Borrar / añadir filas y columnas (R base)

Borrar una columna
Se asigna NULL a la columna, o se selecciona con un signo menos.
mi_tabla$columna <- NULL
# o, si usas número de columna:
mi_tabla <- mi_tabla[ , -2]
Borrar una fila
Igual, pero con el signo menos en la posición de la fila.
mi_tabla <- mi_tabla[-1, ]  # elimina la fila 1
Añadir una columna nueva
Se crea igual que si ya existiera.
mi_tabla$columna_nueva <- mi_tabla$edad * 2

9. Valores especiales y lógica (R base)

is.na() / !is.na()
Comprueba si un valor es NA (dato ausente). Con ! delante, comprueba lo contrario ("que NO sea NA").
is.na(mi_vector)
mi_vector[!is.na(mi_vector)]  # solo los valores que NO son NA
is.null() / is.nan() / is.infinite()
Comprueban si un objeto está "vacío" (NULL), si es un resultado matemático indefinido (NaN, ej. 0/0), o si es infinito.
is.null(mi_valor)
is.nan(0/0)
is.infinite(1/0)
any() / all()
any(): ¿al menos UNO cumple la condición? all(): ¿TODOS la cumplen?
any(is.na(mi_tabla))   # ¿hay algún NA en toda la tabla?
all(mi_tabla$edad > 0)
subset()
Filtra filas de una tabla según una condición (versión base de filter() de dplyr).
subset(mi_tabla, edad > 30)

10. Condicionales y funciones propias (R base)

if / else if / else
Ejecuta código solo si se cumple una condición.
if (mi_valor > 10) {
  print("Mayor que 10")
} else if (mi_valor == 10) {
  print("Es igual a 10")
} else {
  print("Menor que 10")
}
ifelse()
Versión "en una línea" del if/else, ideal para aplicar a una columna entera de golpe.
mi_tabla$categoria <- ifelse(mi_tabla$edad > 18, "adulto", "menor")
function()
Crea tu propia función reutilizable.
mi_funcion <- function(mi_valor) {
  return(mi_valor * 2)
}
mi_funcion(5)  # 10
suppressWarnings()
Ejecuta código sin que se muestren los mensajes de aviso (warnings) en pantalla.
suppressWarnings(as.numeric("abc"))

11. Bucles (loops) (R base)

for
Repite un bloque de código para cada elemento de un vector/rango.
for (i in 1:nrow(mi_tabla)) {
  print(mi_tabla$edad[i])
}
while
Repite el código MIENTRAS se cumpla una condición.
i <- 1
while (i <= 5) {
  print(i)
  i <- i + 1
}
repeat
Repite indefinidamente hasta que uses break para pararlo.
i <- 1
repeat {
  print(i)
  i <- i + 1
  if (i > 5) break
}
next / break
next salta a la siguiente vuelta del bucle sin terminar la actual. break corta el bucle por completo.
for (i in 1:5) {
  if (i == 3) next    # se salta el 3
  if (i == 5) break   # para antes del 5
  print(i)
}

12. Apply y sort (R base)

apply()
Aplica una función a todas las filas (MARGIN = 1) o columnas (MARGIN = 2) de una tabla, sin necesidad de un bucle for.
apply(mi_tabla, 2, mean, na.rm = TRUE)
# media de cada columna
sort()
Ordena un vector de menor a mayor (o al revés con decreasing = TRUE).
sort(mi_vector)
sort(mi_vector, decreasing = TRUE)

13. tidyverse / dplyr tidyverse

library("tidyverse")
Carga el paquete (en realidad, un conjunto de paquetes) que incluye dplyr, usado para manipular tablas de forma legible.
library("tidyverse")
select()
Elige columnas concretas de una tabla.
mi_tabla %>% select(nombre, edad)
filter()
Filtra filas según una condición (el equivalente moderno de subset()).
mi_tabla %>% filter(edad > 30)
arrange()
Ordena las filas según una o varias columnas. Añade desc() para orden descendente.
mi_tabla %>% arrange(edad)
mi_tabla %>% arrange(desc(edad))
distinct()
Elimina filas duplicadas (el equivalente de unique() pero para tablas enteras).
mi_tabla %>% distinct(columna)
group_by() + summarise()
Agrupa filas por una columna y luego calcula un resumen (media, suma...) para cada grupo. Son casi siempre pareja.
mi_tabla %>%
  group_by(categoria) %>%
  summarise(media_edad = mean(edad, na.rm = TRUE))
contains() / starts_with() / ends_with()
Se usan DENTRO de select() para elegir columnas por su nombre parcial.
mi_tabla %>% select(contains("edad"))
mi_tabla %>% select(starts_with("nom"))
mi_tabla %>% select(ends_with("_id"))
slice()
Selecciona filas por su número de posición.
mi_tabla %>% slice(1:5)   # las primeras 5 filas
Nota de ortografía: es summarise() (o summarize(), ambas funcionan), no "summarixe". Y es distinct con "t".

14. Operadores

%>% y |>
Los "pipes": toman lo de la izquierda y lo pasan como primer argumento a la función de la derecha. %>% viene de magrittr/tidyverse; |> es el pipe nativo de R (desde la versión 4.1), hacen básicamente lo mismo.
mi_tabla %>% filter(edad > 30)
# es equivalente a:
mi_tabla |> filter(edad > 30)
== / != / > / >= / < / <=
Operadores de comparación: igual, distinto, mayor, mayor o igual, menor, menor o igual. Siempre devuelven TRUE o FALSE.
mi_valor == 10   # ¿es igual a 10?
mi_valor != 10   # ¿es distinto de 10?
mi_valor >= 18
\n y \t
Caracteres especiales dentro de un texto: \n es un salto de línea, \t es una tabulación.
cat("Hola\nMundo")
# Hola
# Mundo

Practical R Manual

Your cheat sheet of functions, organized by package, with examples that always use the same variables.

function() my_table / my_vector (object) "text" (value) if / for (keyword) # comment package

Variables used consistently in every example

my_table → a data.frame (a table of data).
my_vector → a vector of numbers or text.
column → the name of a column, e.g. "age".
my_value → a single number or text value.
So whenever you see my_table in any example, you'll know it always means "the table we're working with".

1. Basics and files (base R)

getwd()
Tells you which folder R is currently working in.
getwd()
# "C:/Users/your_user/Documents"
setwd()
Changes the working folder. Everything you read or save will go to/come from there unless you specify a full path.
setwd("C:/Users/your_user/Documents/project")
file.create()
Creates a new empty file (e.g. a .csv or .txt) in the working folder.
file.create("data.csv")
print()
Displays an object's content on screen. It's what R does "by default" when you type an object name alone, but print() is useful inside functions, loops, etc.
my_value <- 10
print(my_value)
# [1] 10

Creating, opening and closing a document (script)

• New script: in RStudio, File → New File → R Script (or Ctrl + Shift + N).
• Open an existing script: File → Open File (or Ctrl + O).
• Save: Ctrl + S (saved as .R).
• Close the script: Ctrl + W, or just close the tab.
• Run a line: put the cursor on the line and press Ctrl + Enter.

2. Text and help (base R)

paste()
Joins several pieces of text or values into one, separated by a space (by default).
paste("The value is", my_value)
# "The value is 10"
paste0()
Same as paste() but with no space between elements. Commonly used to build file names.
paste0("file_", "2024", ".csv")
# "file_2024.csv"
collapse =
Argument of paste() / paste0() that joins ALL elements of a vector into a single text string, using the separator you specify.
my_vector <- c("a", "b", "c")
paste(my_vector, collapse = ", ")
# "a, b, c"
?function
Opens the official help page for a function (you need to know the exact name).
?paste
??text
Searches ALL installed documentation for anything related to that word (useful if you don't remember the exact function name).
??paste

Convert a value or object to text, decimal, integer, or numeric respectively.
as.character(123)   # "123"
as.numeric("123")   # 123
as.integer(4.9)     # 4

Adds up all the values in a vector.
sum(my_vector, na.rm = TRUE)

5. Creating and exploring tables (data.frame) (base R)

data.frame()
Creates a new table from vectors (each vector becomes a column).

  name = c("Ana", "Luis"),
  age  = c(25, 30)
)
rbind()
Adds a new row to a table (or combines two tables with the same columns).
my_table <- rbind(my_table, data.frame(name = "Marta", age = 40))

Show or change the column / row names.
colnames(my_table)
colnames(my_table) <- c("name", "age_years")

Selects parts of a table by position. If you leave a slot empty, it takes ALL of that dimension.
my_table[1, ]        # row 1, all columns
my_table[ , 2]       # all rows, column 2
my_table[1, 2]      # row 1, column 2

Accesses a column directly by name (returns a vector).
my_table$column

Number of rows, columns, or both at once.
nrow(my_table)  # number of rows
ncol(my_table)  # number of columns

names()
Same as colnames() for data.frames; also works with lists.
names(my_table)
unique()
Returns the distinct values of a vector or column, with no repeats.
unique(my_table$column)
factor()
Converts a text column into categories (useful for variables like "yes/no", "low/medium/high"...).
my_table$column <- factor(my_table$column)

Extra functions that are very useful for exploring a table

head(my_table)     # first 6 rows
tail(my_table)     # last 6 rows
str(my_table)      # structure: each column's type

9. Special values and logic (base R)

is.na() / !is.na()
Checks whether a value is NA (missing). With ! in front, it checks the opposite ("is NOT NA").
is.na(my_vector)
my_vector[!is.na(my_vector)]  # only the values that are NOT NA
is.null() / is.nan() / is.infinite()
Check whether an object is "empty" (NULL), whether it's an undefined mathematical result (NaN, e.g. 0/0), or whether it's infinite.
is.null(my_value)

is.infinite(1/0)

10. Conditionals and custom functions (base R)

if / else if / else
Runs code only if a condition is met.
if (my_value > 10) {
  print("Greater than 10")
} else if (my_value == 10) {
  print("Equal to 10")
} else {
  print("Less than 10")
}
ifelse()
The "one-line" version of if/else, ideal for applying to an entire column at once.
my_table$category <- ifelse(my_table$age > 18, "adult", "minor")
function()
Creates your own reusable function.
my_function <- function(my_value) {
  return(my_value * 2)
}
my_function(5)  # 10
suppressWarnings()
Runs code without showing warning messages on screen.
suppressWarnings(as.numeric("abc"))

11. Loops (base R)

for
Repeats a block of code for each element of a vector/range.
for (i in 1:nrow(my_table)) {
  print(my_table$age[i])
}
while
Repeats the code WHILE a condition remains true.
i <- 1
while (i <= 5) {
  print(i)
  i <- i + 1
}
repeat
Repeats indefinitely until you use break to stop it.
i <- 1
repeat {
  print(i)
  i <- i + 1
  if (i > 5) break
}
next / break
next skips to the next iteration of the loop without finishing the current one. break stops the loop entirely.
for (i in 1:5) {
  if (i == 3) next    # skips 3
  if (i == 5) break   # stops before 5
  print(i)
}

12. Apply and sort (base R)

apply()
Applies a function to every row (MARGIN = 1) or column (MARGIN = 2) of a table, without needing a for loop.
apply(my_table, 2, mean, na.rm = TRUE)
# mean of each column
sort()
Sorts a vector from smallest to largest (or the other way around with decreasing = TRUE).
sort(my_vector)
sort(my_vector, decreasing = TRUE)

13. tidyverse / dplyr tidyverse

library("tidyverse")
Loads the package (actually a bundle of packages) that includes dplyr, used for manipulating tables in a readable way.
library("tidyverse")
select()
Picks specific columns from a table.
my_table %>% select(name, age)
filter()
Filters rows based on a condition (the modern equivalent of subset()).
my_table %>% filter(age > 30)
arrange()
Sorts rows by one or more columns. Add desc() for descending order.
my_table %>% arrange(age)
my_table %>% arrange(desc(age))
distinct()
Removes duplicate rows (the table-level equivalent of unique()).
my_table %>% distinct(column)
group_by() + summarise()
Groups rows by a column and then calculates a summary (mean, sum...) for each group. They almost always go together.
my_table %>%
  group_by(category) %>%
  summarise(mean_age = mean(age, na.rm = TRUE))
contains() / starts_with() / ends_with()
Used INSIDE select() to pick columns by a partial name match.
my_table %>% select(contains("age"))
my_table %>% select(starts_with("nam"))
my_table %>% select(ends_with("_id"))
slice()
Selects rows by their position number.
my_table %>% slice(1:5)   # the first 5 rows
Spelling note: it's summarise() (or summarize(), both work), not "summarixe". And it's distinct with a "t".

14. Operators

%>% and |>
The "pipes": they take whatever is on the left and pass it as the first argument to the function on the right. %>% comes from magrittr/tidyverse; |> is R's native pipe (since version 4.1) — both do basically the same thing.
my_table %>% filter(age > 30)
# is equivalent to:
my_table |> filter(age > 30)
== / != / > / >= / < / <=
Comparison operators: equal to, not equal to, greater than, greater than or equal, less than, less than or equal. They always return TRUE or FALSE.
my_value == 10   # is it equal to 10?
my_value != 10   # is it different from 10?
