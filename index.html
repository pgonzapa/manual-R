Manual práctico de R

Tu chuleta de funciones, ordenada por paquetes, con ejemplos siempre con las mismas variables.

función() mi_tabla / mi_vector (objeto) "texto" (valor) if / for (palabra clave) # comentario paquete

Variables que se repiten en todos los ejemplos

mi_tabla → un data.frame (tabla de datos).
mi_vector → un vector de números o texto.
columna → el nombre de una columna, ej. "edad".
mi_valor → un único número o texto.
Así, cuando veas mi_tabla en cualquier ejemplo, sabrás que siempre es "la tabla con la que estamos trabajando".

1. Lo básico y archivos (R base)

getwd()
Te dice en qué carpeta está trabajando R ahora mismo.
getwd()
# "C:/Users/tu_usuario/Documents"
setwd()
Cambia la carpeta de trabajo. Todo lo que leas o guardes irá/vendrá de ahí si no pones ruta completa.
setwd("C:/Users/tu_usuario/Documents/proyecto")
file.create()
Crea un archivo vacío nuevo (por ejemplo, un .csv o .txt vacío) en la carpeta de trabajo.
file.create("datos.csv")
print()
Muestra en pantalla el contenido de un objeto. Es lo que R hace "por defecto" cuando escribes un nombre solo, pero print() es útil dentro de funciones, loops, etc.
mi_valor <- 10
print(mi_valor)
# [1] 10

Crear, abrir y cerrar un documento (script)

• Crear script nuevo: en RStudio, menú File → New File → R Script (o Ctrl + Shift + N).
• Abrir un script existente: File → Open File (o Ctrl + O).
• Guardar: Ctrl + S (se guarda como .R).
• Cerrar el script: Ctrl + W, o simplemente la "x" de la pestaña.
• Ejecutar una línea: pon el cursor en la línea y pulsa Ctrl + Enter.

2. Texto y ayuda (R base)

cat()
Concatena (junta) varios valores de texto o números y los imprime directamente en la consola, sin comillas ni el [1] que muestra print(). Es ideal para mensajes legibles, sobre todo combinado con \n para saltos de línea.
cat("El valor es", mi_valor, "\n")
# El valor es 10
cat() no añade comillas a los textos ni numeración a la izquierda; por eso se usa mucho para imprimir resultados de tests o mensajes personalizados (ej. cat("Test superado :)\n")).
paste()
Une varios textos o valores en uno solo, separados por espacio (por defecto).
paste("El valor es", mi_valor)
# "El valor es 10"
paste0()
Igual que paste() pero sin espacio entre los elementos. Muy usado para construir nombres de archivo.
paste0("archivo_", "2024", ".csv")
# "archivo_2024.csv"
collapse =
Argumento de paste() / paste0() que junta TODOS los elementos de un vector en un solo texto, usando el separador que indiques.
mi_vector <- c("a", "b", "c")
paste(mi_vector, collapse = ", ")
# "a, b, c"
?funcion
Abre la ayuda oficial de una función (necesitas saber el nombre exacto).
?paste
??texto
Busca en TODA la documentación instalada cualquier función relacionada con esa palabra (útil si no recuerdas el nombre exacto).
??paste

5. Crear y explorar tablas (data.frame) (R base)

data.frame()
Crea una tabla nueva a partir de vectores (cada vector es una columna).
mi_tabla <- data.frame(
  nombre = c("Ana", "Luis"),
  edad   = c(25, 30)
)
rbind()
Añade una fila nueva a una tabla (o une dos tablas con las mismas columnas).
mi_tabla <- rbind(mi_tabla, data.frame(nombre = "Marta", edad = 40))
colnames() / rownames()
Muestran o cambian los nombres de columnas / filas.
colnames(mi_tabla)
colnames(mi_tabla) <- c("nombre", "edad_anios")
mi_tabla[fila, columna]
Selecciona partes de la tabla por posición. Si dejas un hueco vacío, coge TODO en esa dimensión.
mi_tabla[1, ]        # fila 1, todas las columnas
mi_tabla[ , 2]       # todas las filas, columna 2
mi_tabla[1, 2]      # fila 1, columna 2
mi_tabla$columna
Accede directamente a una columna por su nombre (devuelve un vector).
mi_tabla$columna
nrow() / ncol() / dim()
Número de filas, columnas, o ambos a la vez.
nrow(mi_tabla)  # nº de filas
ncol(mi_tabla)  # nº de columnas
dim(mi_tabla)   # c(filas, columnas)
names()
Igual que colnames() para data.frames; también funciona con listas.
names(mi_tabla)
unique()
Devuelve los valores distintos de un vector o columna, sin repetir.
unique(mi_tabla$columna)
factor()
Convierte una columna de texto en categorías (útil para variables tipo "sí/no", "bajo/medio/alto"...).
mi_tabla$columna <- factor(mi_tabla$columna)

Extras muy útiles para explorar una tabla

6. Borrar / añadir filas y columnas (R base)

Borrar una columna
Se asigna NULL a la columna, o se selecciona con un signo menos.
mi_tabla$columna <- NULL
# o, si usas número de columna:
mi_tabla <- mi_tabla[ , -2]
Borrar una fila
Igual, pero con el signo menos en la posición de la fila.
mi_tabla <- mi_tabla[-1, ]  # elimina la fila 1
Añadir una columna nueva
Se crea igual que si ya existiera.
mi_tabla$columna_nueva <- mi_tabla$edad * 2

8. Estadística básica (R base)

mean() / median()
Media y mediana de un vector o columna.
mean(mi_tabla$columna, na.rm = TRUE)
median(mi_tabla$columna, na.rm = TRUE)
rowMeans() / colMeans()
Calculan la media de cada FILA (rowMeans()) o de cada COLUMNA (colMeans()) a la vez, sin necesidad de bucles. Muy útil para crear una columna "media" a partir de varias columnas numéricas.
mi_tabla$media <- rowMeans(mi_tabla[, c("col1", "col2", "col3")], na.rm = TRUE)
# crea una nueva columna "media" con la media por fila de col1, col2 y col3
Recuerda: na.rm = TRUE le dice a R "si encuentras algún NA, ignóralo y calcula igualmente" (si no lo pones, el resultado sería NA en cuanto hubiera un solo hueco).
quantile()
Calcula los cuartiles (o el percentil que pidas) de un vector.
quantile(mi_tabla$columna, na.rm = TRUE)
which()
Devuelve las POSICIONES donde se cumple una condición (no el valor, la posición).
which(mi_tabla$edad > 30)
# [1] 3 5   (filas 3 y 5 cumplen la condición)

9. Valores especiales y lógica (R base)

is.na() / !is.na()
Comprueba si un valor es NA (dato ausente). Con ! delante, comprueba lo contrario ("que NO sea NA").
is.na(mi_vector)
mi_vector[!is.na(mi_vector)]  # solo los valores que NO son NA
is.null() / is.nan() / is.infinite()
Comprueban si un objeto está "vacío" (NULL), si es un resultado matemático indefinido (NaN, ej. 0/0), o si es infinito.
is.null(mi_valor)
is.nan(0/0)
is.infinite(1/0)
any() / all()
any(): ¿al menos UNO cumple la condición? all(): ¿TODOS la cumplen?
any(is.na(mi_tabla))   # ¿hay algún NA en toda la tabla?
all(mi_tabla$edad > 0)
subset()
Filtra filas de una tabla según una condición (versión base de filter() de dplyr).
subset(mi_tabla, edad > 30)

10. Condicionales y funciones propias (R base)

if / else if / else
Ejecuta código solo si se cumple una condición.
if (mi_valor > 10) {
  print("Mayor que 10")
} else if (mi_valor == 10) {
  print("Es igual a 10")
} else {
  print("Menor que 10")
}
ifelse()
Versión "en una línea" del if/else, ideal para aplicar a una columna entera de golpe.
mi_tabla$categoria <- ifelse(mi_tabla$edad > 18, "adulto", "menor")
function()
Crea tu propia función reutilizable.
mi_funcion <- function(mi_valor) {
  return(mi_valor * 2)
}
mi_funcion(5)  # 10
suppressWarnings()
Ejecuta código sin que se muestren los mensajes de aviso (warnings) en pantalla.
suppressWarnings(as.numeric("abc"))

11. Bucles (loops) (R base)

for
Repite un bloque de código para cada elemento de un vector/rango.
for (i in 1:nrow(mi_tabla)) {
  print(mi_tabla$edad[i])
}
while
Repite el código MIENTRAS se cumpla una condición.
i <- 1
while (i <= 5) {
  print(i)
  i <- i + 1
}
repeat
Repite indefinidamente hasta que uses break para pararlo.
i <- 1
repeat {
  print(i)
  i <- i + 1
  if (i > 5) break
}
next / break
next salta a la siguiente vuelta del bucle sin terminar la actual. break corta el bucle por completo.
for (i in 1:5) {
  if (i == 3) next    # se salta el 3
  if (i == 5) break   # para antes del 5
  print(i)
}

Ordena un vector de menor a mayor (o al revés con decreasing = TRUE).

13. Funciones robustas y tests (R base + testthat)

warning() / stop()
Dentro de una función propia, warning() muestra un aviso pero DEJA CONTINUAR la ejecución; stop() corta la ejecución de golpe con un mensaje de error. Se usan para que tu función avise cuando algo no va bien con los datos de entrada.
average <- function(x) {
  if(any(is.na(x))){
    warning("'x' contains one or more NA values.")
    return(NA)
  }
  if(!is.numeric(x)) {
    stop("'x' must be a numeric vector.")
  }
  sum(x)/length(x)
}
Diferencia clave: un warning dice "ojo con esto, pero sigo"; un error (stop()) dice "no puedo continuar, paro aquí". Fíjate en el orden: primero se comprueban los NA (que dan warning), y solo si no hay problema con eso se comprueba el tipo (que da error) — así cada problema tiene su propio aviso.
Tests manuales (sin librerías)
Antes de usar un paquete de testing, puedes comprobar "a mano" que tu función da el resultado esperado, usando un if normal y cat() para el mensaje.
test_average <- function() {
  if(average(c(1,2,3))==2) {
    cat("'average' passed test :)\n")
  } else {
    cat("'average' failed the test :(\n")
  }
}
test_average()
Este método funciona, pero se vuelve incómodo con muchos casos: no agrupa los tests, no cuenta cuántos pasan o fallan, y hay que escribir el if/else cada vez. Para eso existe el paquete testthat.
testthat
install.packages("testthat") + library(testthat)
Paquete estándar de R para escribir tests de forma ordenada. Se instala una sola vez y se carga con library() en cada sesión donde lo vayas a usar.
install.packages("testthat")
library("testthat")
testthat
test_that()
Agrupa una o varias comprobaciones (expect_*) bajo una misma descripción. Un test_that() = un test, aunque contenga varias expectativas dentro. Si TODAS las expectativas se cumplen, se imprime un único mensaje de éxito (ej. "Test passed 🎉"); si alguna falla, todo el bloque se marca como fallido, indicando cuál expectativa concreta ha fallado.
test_that("'average' calculates mean", {
  expect_equal(average(c(1,2,3)),2)
  expect_equal(average(c(-1,2,3)),2)
})
testthat
expect_equal() / expect_warning()
expect_equal() comprueba que el resultado sea EXACTAMENTE el valor esperado. expect_warning() comprueba que la expresión lance un warning() (no comprueba el valor devuelto, solo que avise).
test_that("'average' calculates mean", {
  expect_warning(average(c(1,NA,3)))
  expect_warning(average(c(NA,NA,3)))
})

test_that("'average' returns NA with NAs in input", {
  expect_equal(suppressWarnings(average(c(1,NA,3))),NA)
  expect_equal(suppressWarnings(average(c(NA,NA,NA))),NA)
})
¿Por qué suppressWarnings() aquí? Porque average() lanza un warning() cuando hay NA; si no lo silencias, el aviso "ensucia" la consola al comprobar el valor devuelto, aunque el test siga pasando igual.

¿Cómo sé si un test ha pasado?

Si ejecutas un expect_* SUELTO en la consola (fuera de test_that()), no verás ningún mensaje si pasa — expect_* solo "hace ruido" cuando FALLA. Para ver un resumen claro, ejecuta el bloque test_that() completo (te dirá "Test passed" o el detalle del fallo), o corre el archivo entero con:

testthat::test_file("test-average.R")
# [ FAIL 0 | WARN 0 | SKIP 0 | PASS 6 ]

PASS 6 cuenta cada expect_* individual que ha pasado, no cada test_that() (aquí hay 3 bloques test_that() con 6 expectativas en total).

14. tidyr: reorganizar tablas tidyr

library(tidyr)
Carga el paquete tidyr (incluido en tidyverse), especializado en cambiar la "forma" de una tabla —pasar de formato largo a ancho o viceversa— sin cambiar la información que contiene.
library("tidyr")
pivot_wider()
Convierte filas en columnas ("ensancha" la tabla). Muy útil cuando tienes una columna que en realidad debería repartirse en varias columnas distintas (ej. una fila por cada persona+categoría, y quieres una columna por categoría).
mi_tabla_ancha <- pivot_wider(
  mi_tabla,
  id_cols     = id,
  names_from  = categoria,
  values_from = valor
)
id_cols: la(s) columna(s) que identifican de forma única cada fila del resultado (lo que NO se reparte en columnas).
names_from: la columna cuyos VALORES se convertirán en los NOMBRES de las nuevas columnas.
values_from: la columna cuyos VALORES rellenarán esas nuevas columnas.

Ejemplo visual

Si tienes esto (formato largo, una fila por combinación):

id  categoria  valor
1   A          10
1   B          20
2   A          15
2   B          25

con pivot_wider(id_cols = id, names_from = categoria, values_from = valor) obtienes (formato ancho, una fila por id):

id  A   B
1   10  20
2   15  25

Su opuesto es pivot_longer() (columnas → filas): no se cubre aquí, pero es la función complementaria que conviene conocer.

15. tidyverse / dplyr tidyverse

library("tidyverse")
Carga el paquete (en realidad, un conjunto de paquetes) que incluye dplyr, usado para manipular tablas de forma legible.
library("tidyverse")
select()
Elige columnas concretas de una tabla.
mi_tabla %>% select(nombre, edad)
filter()
Filtra filas según una condición (el equivalente moderno de subset()).
mi_tabla %>% filter(edad > 30)
arrange()
Ordena las filas según una o varias columnas. Añade desc() para orden descendente.
mi_tabla %>% arrange(edad)
mi_tabla %>% arrange(desc(edad))
distinct()
Elimina filas duplicadas (el equivalente de unique() pero para tablas enteras).
mi_tabla %>% distinct(columna)
group_by() + summarise()
Agrupa filas por una columna y luego calcula un resumen (media, suma...) para cada grupo. Son casi siempre pareja.
mi_tabla %>%
  group_by(categoria) %>%
  summarise(media_edad = mean(edad, na.rm = TRUE))
summarise() a solas
No hace falta agrupar para usar summarise(): usado sin group_by() antes, calcula el resumen para TODA la tabla de una vez. El nombre que pongas a la izquierda (ej. media) será el nombre de la columna resultante.
mi_tabla %>%
  summarise(media = mean(columna, na.rm = TRUE))
group_by() + summarise(n = n())
n() cuenta cuántas filas hay en cada grupo. Combinado con group_by(), es la forma más habitual de contar cuántas veces aparece cada categoría (ej. cuántos votos ha recibido cada opción).
mi_tabla %>%
  group_by(candidato) %>%
  summarise(votos = n())
ungroup()
Quita la agrupación creada por group_by(). Es buena práctica usarlo después de terminar de resumir por grupos, para que los pasos siguientes (ej. arrange()) trabajen sobre toda la tabla y no grupo a grupo.
mi_tabla %>%
  group_by(candidato) %>%
  summarise(votos = n()) %>%
  ungroup() %>%
  arrange(desc(votos))
Este patrón completo —agrupar, contar, desagrupar y ordenar de mayor a menor— es exactamente el flujo típico para responder "¿qué categoría es la más frecuente?".
contains() / starts_with() / ends_with()
Se usan DENTRO de select() para elegir columnas por su nombre parcial.
mi_tabla %>% select(contains("edad"))
mi_tabla %>% select(starts_with("nom"))
mi_tabla %>% select(ends_with("_id"))
slice()
Selecciona filas por su número de posición.
mi_tabla %>% slice(1:5)   # las primeras 5 filas

16. stringr: limpiar texto stringr

library(stringr)
Carga stringr (parte de tidyverse), el paquete de referencia para trabajar con texto: quitar espacios, cambiar mayúsculas/minúsculas, buscar patrones...
library("stringr")
str_trim() / str_squish()
str_trim() quita los espacios en blanco al PRINCIPIO y al FINAL del texto. str_squish() hace lo mismo Y ADEMÁS reduce los espacios repetidos EN MEDIO del texto a uno solo.
mi_tabla$columna <- str_trim(mi_tabla$columna)

# o encadenado con pipe:
mi_tabla$columna <- mi_tabla$columna %>%
  str_trim() %>%
  str_squish()
str_to_lower() / str_to_upper() / str_to_title()
Cambian las mayúsculas/minúsculas de un texto: todo minúsculas, todo mayúsculas, o solo la primera letra de cada palabra en mayúscula.
str_to_lower("HOLA MUNDO")   # "hola mundo"
str_to_upper("hola mundo")   # "HOLA MUNDO"
str_to_title("hola mundo")   # "Hola Mundo"
str_detect()
Comprueba si un texto CONTIENE un patrón determinado. Devuelve TRUE/FALSE por cada elemento del vector, no el texto en sí.
str_detect(mi_tabla$columna, "Avatar")
# [1] FALSE  TRUE FALSE  TRUE ...
columna[str_detect(...)]
Combinando str_detect() con corchetes [ ], obtienes los valores EXACTOS (no solo TRUE/FALSE) que cumplen la condición: qué han puesto realmente, y en qué fila.
mi_tabla$columna[str_detect(mi_tabla$columna, "Avatar")]
# "Avatar", "Avatar 2", "avatar"...  (todo lo que contenga "Avatar")
Reasignar los valores detectados
El mismo patrón, pero con una asignación <-, sirve para REEMPLAZAR todos los valores que cumplan la condición por uno nuevo (útil para unificar variantes de un mismo texto).
mi_tabla$columna[str_detect(mi_tabla$columna, "Avatar")] <- "Avatar2"
# todo lo que contenía "Avatar" pasa a valer exactamente "Avatar2"
Un flujo de limpieza de texto típico es: str_trim() / str_squish() (quitar espacios sobrantes) → str_to_lower() o str_to_title() (unificar mayúsculas) → str_detect() (agrupar variantes parecidas bajo un mismo valor).

17. Visualización de datos: ggplot2 ggplot2

library(ggplot2) + library(tidyverse)
ggplot2 es el paquete de gráficos de R, basado en capas: primero defines los datos y los ejes, y luego vas "sumando" capas con + (puntos, columnas, líneas, colores, títulos...).
library("ggplot2")
library("tidyverse")  # ya incluye ggplot2
ggplot() + geom_col()
Crea un gráfico de columnas (barras). ggplot() define los datos y los ejes dentro de aes() ("aesthetic mappings"); geom_col() añade la capa de columnas.
ggplot(mi_tabla, aes(x = candidato, y = votos)) +
  geom_col()
x e y dentro de aes() indican qué columna va en cada eje: x es el eje horizontal, y el vertical.
scale_x_continuous() / scale_y_continuous() / scale_x_discrete() / scale_y_discrete()
Controlan cómo se muestra cada eje. Usa las versiones _continuous cuando el eje es numérico (ej. votos, precio) y las _discrete cuando es categórico (ej. nombres, grupos). Con limits = c(min, max) fijas el rango visible del eje.
scale_y_continuous(limits = c(0, 250))
# el primer número es el mínimo del eje Y, el segundo el máximo
labs()
Añade o cambia los textos del gráfico: título de los ejes, título general, subtítulo...
labs(
  x = "candidate",
  y = "votes",
  title = "resultados"
)
fill = (color por grupo)
Dentro de aes(), fill = colorea cada columna según el valor de una columna categórica: cada categoría recibe automáticamente su propio color.
geom_col(aes(fill = candidate))
# candidate es el nombre de la columna con los datos de cada columna del gráfico
scale_fill_viridis_d() / scale_fill_viridis_c()
Cambia la paleta de colores usada por fill (o color) a la paleta "viridis", diseñada para seguir siendo legible incluso para personas daltónicas. El sufijo _d es para variables discretas (categorías); _c es para variables continuas (números).
scale_fill_viridis_d()   # para categorías (discreta)
scale_fill_viridis_c()   # para valores numéricos (continua)
show.legend = FALSE
Argumento de una capa geom_* que oculta la leyenda de color/relleno de esa capa concreta.
geom_col(aes(fill = candidate), show.legend = FALSE)
theme_classic() / theme_minimal()
Aplican un estilo visual predefinido a todo el gráfico. theme_classic() usa ejes con línea sólida sobre fondo blanco; theme_minimal() quita casi todos los elementos decorativos (fondo, bordes) para un aspecto más limpio.
p <- ggplot(mi_tabla, aes(x = candidato, y = votos)) +
  geom_col() +
  theme_classic()
ggsave()
Guarda el último gráfico creado (o el que le indiques en plot =) como archivo de imagen.
ggsave(
  "votes.png",   # nombre del archivo de salida
  plot   = p,        # qué gráfico guardar (el objeto creado con ggplot)
  width  = 1200,     # ancho de la imagen
  height = 900,      # alto de la imagen
  units  = "px"      # unidades: "px" (píxeles), "in" (pulgadas) o "cm"
)
Si no indicas plot =, ggsave() guarda automáticamente el último gráfico que se ha dibujado en pantalla.
geom_point() / geom_jitter()
Ambos dibujan un punto por fila (gráfico de dispersión). El problema de geom_point() es que, si varios puntos tienen exactamente el mismo valor, se dibujan uno ENCIMA de otro y parecen menos puntos de los que realmente hay (solapamiento). geom_jitter() soluciona esto añadiendo un pequeño desplazamiento aleatorio para poder distinguirlos.
ggplot(data_frame, aes(x = Price, y = sugar)) +
  geom_jitter(color = "darkorchid", size = 2)
Cuidado con el solapamiento: si tus datos son categóricos o tienen muchos valores repetidos, usa siempre geom_jitter() en vez de geom_point() para no perder información visual por puntos ocultos entre sí.
Ejemplo completo: serie temporal con línea, puntos y umbral
Ejemplo combinando varias capas: una línea discontinua, puntos encima, y una línea horizontal de referencia (umbral) con geom_hline(). Antes, se convierte la columna de fecha/hora (texto) a un formato de fecha real con ymd_hms() (del paquete lubridate, incluido en tidyverse).
anita <- anita %>%
  mutate(timestamp = ymd_hms(timestamp))

ggplot(anita, aes(x = timestamp, y = wind)) +
  geom_line(color = "deepskyblue4", alpha = 0.4, linetype = 2) +
  geom_point(color = "deepskyblue4", size = 2) +
  geom_hline(yintercept = 24, color = "black", linetype = 3) +
  theme_classic()
mutate() (de dplyr) crea o modifica una columna dentro de un pipe; aquí convierte texto a fecha-hora real.
alpha controla la transparencia (0 = invisible, 1 = opaco). linetype cambia el estilo de línea (1 = sólida, 2 = discontinua, 3 = punteada...). geom_hline() dibuja una línea horizontal fija en yintercept, muy útil para marcar un límite o umbral de referencia.

13. Robust functions and tests (base R + testthat)

warning() / stop()
Inside your own function, warning() shows an alert but LETS EXECUTION CONTINUE; stop() halts execution immediately with an error message. They're used so your function can flag problems with its input.
average <- function(x) {
  if(any(is.na(x))){
    warning("'x' contains one or more NA values.")
    return(NA)
  }
  if(!is.numeric(x)) {
    stop("'x' must be a numeric vector.")
  }
  sum(x)/length(x)
}
Key difference: a warning says "heads up, but I'll carry on"; an error (stop()) says "I can't continue, stopping here". Notice the order: NA values are checked first (warning), and only if that's fine is the type checked (error) — so each problem gets its own kind of alert.
Manual tests (no packages)
Before reaching for a testing package, you can check "by hand" that your function returns what you expect, using a plain if and cat() for the message.
test_average <- function() {
  if(average(c(1,2,3))==2) {
    cat("'average' passed test :)\n")
  } else {
    cat("'average' failed the test :(\n")
  }
}
test_average()
This works, but it gets clunky with many cases: it doesn't group tests together, doesn't count how many pass/fail, and you have to write the if/else every time. That's what the testthat package is for.
testthat
install.packages("testthat") + library(testthat)
R's standard package for writing tests in an organized way. Install it once and load it with library() in every session where you'll use it.
install.packages("testthat")
library("testthat")
testthat
test_that()
Groups one or more checks (expect_*) under one description. One test_that() = one test, even if it contains several expectations inside. If ALL expectations pass, you get a single success message (e.g. "Test passed 🎉"); if any fails, the whole block is marked as failed, showing which specific expectation broke.
test_that("'average' calculates mean", {
  expect_equal(average(c(1,2,3)),2)
  expect_equal(average(c(-1,2,3)),2)
})
testthat
expect_equal() / expect_warning()
expect_equal() checks that the result is EXACTLY the expected value. expect_warning() checks that the expression throws a warning() (it doesn't check the returned value, just that it warns).
test_that("'average' calculates mean", {
  expect_warning(average(c(1,NA,3)))
  expect_warning(average(c(NA,NA,3)))
})

test_that("'average' returns NA with NAs in input", {
  expect_equal(suppressWarnings(average(c(1,NA,3))),NA)
  expect_equal(suppressWarnings(average(c(NA,NA,NA))),NA)
})
Why suppressWarnings() here? Because average() throws a warning() whenever there's an NA; if you don't silence it, the alert "clutters" the console while checking the returned value, even though the test still passes.

How do I know if a test passed?

If you run a lone expect_* in the console (outside test_that()), you won't see any message when it passes — expect_* only "makes noise" when it FAILS. For a clear summary, run the whole test_that() block (it will tell you "Test passed" or the failure details), or run the entire file with:

testthat::test_file("test-average.R")
# [ FAIL 0 | WARN 0 | SKIP 0 | PASS 6 ]

PASS 6 counts each individual expect_* that passed, not each test_that() (here there are 3 test_that() blocks with 6 expectations in total).

14. tidyr: reshaping tables tidyr

library(tidyr)
Loads the tidyr package (included in tidyverse), specialized in changing the "shape" of a table — going from long to wide format or vice versa — without changing the information it holds.

pivot_wider()
Turns rows into columns (makes the table "wider"). Very useful when you have a column that should really be split into several separate columns (e.g. one row per person+category, and you want one column per category).
my_wide_table <- pivot_wider(
  my_table,
  id_cols     = id,
  names_from  = category,
  values_from = value
)
id_cols: the column(s) that uniquely identify each row of the result (what does NOT get split into columns).
names_from: the column whose VALUES will become the NAMES of the new columns.
values_from: the column whose VALUES will fill those new columns.

Visual example

If you have this (long format, one row per combination):

id  category  value
1   A         10
1   B         20
2   A         15
2   B         25

with pivot_wider(id_cols = id, names_from = category, values_from = value) you get (wide format, one row per id):

id  A   B
1   10  20
2   15  25

Its opposite is pivot_longer() (columns → rows): not covered here, but the complementary function worth knowing.

Loads the package (actually a bundle of packages) that includes dplyr, used for manipulating tables in a readable way.

select()
Picks specific columns from a table.

Filters rows based on a condition (the modern equivalent of subset()).
my_table %>% filter(age > 30)

Sorts rows by one or more columns. Add desc() for descending order.
my_table %>% arrange(age)

Removes duplicate rows (the table-level equivalent of unique()).

group_by() + summarise()
Groups rows by a column and then calculates a summary (mean, sum...) for each group. They almost always go together.
my_table %>%
  group_by(category) %>%

summarise() on its own
You don't need to group first to use summarise(): used without a prior group_by(), it computes the summary for the WHOLE table at once. The name you give it on the left (e.g. mean_value) becomes the name of the resulting column.
my_table %>%
  summarise(mean_value = mean(column, na.rm = TRUE))
group_by() + summarise(n = n())
n() counts how many rows there are in each group. Combined with group_by(), it's the standard way to count how many times each category appears (e.g. how many votes each option received).
my_table %>%
  group_by(candidate) %>%
  summarise(votes = n())
ungroup()
Removes the grouping created by group_by(). It's good practice to use it once you're done summarizing by group, so later steps (e.g. arrange()) operate on the whole table rather than group by group.
my_table %>%
  group_by(candidate) %>%
  summarise(votes = n()) %>%
  ungroup() %>%
  arrange(desc(votes))
This whole pattern — group, count, ungroup, and sort from most to least — is exactly the typical flow for answering "which category is the most frequent?".
contains() / starts_with() / ends_with()
Used INSIDE select() to pick columns by a partial name match.

my_table %>% select(ends_with("_id"))
slice()
Selects rows by their position number.

16. stringr: cleaning text stringr

library(stringr)
Loads stringr (part of tidyverse), the go-to package for working with text: trimming spaces, changing case, searching for patterns...
library("stringr")
str_trim() / str_squish()
str_trim() removes whitespace at the BEGINNING and END of the text. str_squish() does the same AND ALSO collapses repeated whitespace IN THE MIDDLE of the text down to a single space.
my_table$column <- str_trim(my_table$column)

# or chained with a pipe:
my_table$column <- my_table$column %>%
  str_trim() %>%
  str_squish()
str_to_lower() / str_to_upper() / str_to_title()
Change the case of a text: all lowercase, all uppercase, or only the first letter of each word capitalized.
str_to_lower("HELLO WORLD")   # "hello world"
str_to_upper("hello world")   # "HELLO WORLD"
str_to_title("hello world")   # "Hello World"
str_detect()
Checks whether a text CONTAINS a given pattern. Returns TRUE/FALSE for each element of the vector, not the text itself.
str_detect(my_table$column, "Avatar")
# [1] FALSE  TRUE FALSE  TRUE ...
column[str_detect(...)]
Combining str_detect() with brackets [ ] gets you the EXACT values (not just TRUE/FALSE) that meet the condition — i.e. what people actually wrote, and in which row.
my_table$column[str_detect(my_table$column, "Avatar")]
# "Avatar", "Avatar 2", "avatar"...  (anything containing "Avatar")
Reassigning the detected values
The same pattern, but with an assignment <-, lets you REPLACE every value matching the condition with a new one (handy for merging variants of the same text into one).
my_table$column[str_detect(my_table$column, "Avatar")] <- "Avatar2"
# everything that contained "Avatar" now becomes exactly "Avatar2"
A typical text-cleaning flow is: str_trim() / str_squish() (remove extra spaces) → str_to_lower() or str_to_title() (unify case) → str_detect() (group similar variants under one value).

Argument of a geom_* layer that hides the color/fill legend for that specific layer.
geom_col(aes(fill = candidate), show.legend = FALSE)
theme_classic() / theme_minimal()
Apply a predefined visual style to the whole chart. theme_classic() uses solid axis lines on a white background; theme_minimal() strips away almost all decorative elements (background, borders) for a cleaner look.
p <- ggplot(my_table, aes(x = candidate, y = votes)) +
  geom_col() +
  theme_classic()
ggsave()
Saves the last chart created (or the one you pass in plot =) as an image file.
ggsave(
  "votes.png",   # output file name
  plot   = p,        # which chart to save (the object created with ggplot)
  width  = 1200,     # image width
  height = 900,      # image height
  units  = "px"      # units: "px" (pixels), "in" (inches) or "cm"
)
If you don't specify plot =, ggsave() automatically saves the last chart drawn on screen.
geom_point() / geom_jitter()
Both draw one point per row (scatter plot). The problem with geom_point() is that if several points share the exact same value, they get drawn ON TOP of each other and look like fewer points than there really are (overlap). geom_jitter() fixes this by adding a small random offset so you can tell them apart.
ggplot(data_frame, aes(x = Price, y = sugar)) +
  geom_jitter(color = "darkorchid", size = 2)
Watch out for overlap: if your data is categorical or has many repeated values, always use geom_jitter() instead of geom_point() so you don't lose visual information to hidden points.
Full example: time series with a line, points and a threshold
Example combining several layers: a dashed line, points on top, and a horizontal reference line (threshold) with geom_hline(). First, the date/time column (text) is converted into a real date format with ymd_hms() (from the lubridate package, included in tidyverse).
anita <- anita %>%
  mutate(timestamp = ymd_hms(timestamp))

ggplot(anita, aes(x = timestamp, y = wind)) +
  geom_line(color = "deepskyblue4", alpha = 0.4, linetype = 2) +
  geom_point(color = "deepskyblue4", size = 2) +
  geom_hline(yintercept = 24, color = "black", linetype = 3) +
  theme_classic()
mutate() (from dplyr) creates or modifies a column inside a pipe; here it converts text into a real date-time.
alpha controls transparency (0 = invisible, 1 = opaque). linetype changes the line style (1 = solid, 2 = dashed, 3 = dotted...). geom_hline() draws a fixed horizontal line at yintercept, very useful for marking a limit or reference threshold.

18. Operators

%>% and |>
The "pipes": they take whatever is on the left and pass it as the first argument to the function on the right. %>% comes from magrittr/tidyverse; |> is R's native pipe (since version 4.1) — both do basically the same thing.
my_table %>% filter(age > 30)
# is equivalent to:
my_table |> filter(age > 30)
== / != / > / >= / < / <=
Comparison operators: equal to, not equal to, greater than, greater than or equal, less than, less than or equal. They always return TRUE or FALSE.
my_value == 10   # is it equal to 10?
my_value != 10   # is it different from 10?
my_value >= 18
\n and \t
Special characters inside a text string: \n is a line break, \t is a tab.
cat("Hello\nWorld")
# Hello
# World
