Manual práctico de R

Tu chuleta de funciones, ordenada por paquetes, con ejemplos siempre con las mismas variables.

función() mi_tabla / mi_vector (objeto) "texto" (valor) if / for (palabra clave) # comentario paquete

Variables que se repiten en todos los ejemplos

mi_tabla → un data.frame (tabla de datos).
mi_vector → un vector de números o texto.
columna → el nombre de una columna, ej. "edad".
mi_valor → un único número o texto.
Así, cuando veas mi_tabla en cualquier ejemplo, sabrás que siempre es "la tabla con la que estamos trabajando".

1. Lo básico y archivos (R base)

getwd()
Te dice en qué carpeta está trabajando R ahora mismo.
getwd()
# "C:/Users/tu_usuario/Documents"
setwd()
Cambia la carpeta de trabajo. Todo lo que leas o guardes irá/vendrá de ahí si no pones ruta completa.
setwd("C:/Users/tu_usuario/Documents/proyecto")
file.create()
Crea un archivo vacío nuevo (por ejemplo, un .csv o .txt vacío) en la carpeta de trabajo.
file.create("datos.csv")
print()
Muestra en pantalla el contenido de un objeto. Es lo que R hace "por defecto" cuando escribes un nombre solo, pero print() es útil dentro de funciones, loops, etc.
mi_valor <- 10
print(mi_valor)
# [1] 10

Crear, abrir y cerrar un documento (script)

• Crear script nuevo: en RStudio, menú File → New File → R Script (o Ctrl + Shift + N).
• Abrir un script existente: File → Open File (o Ctrl + O).
• Guardar: Ctrl + S (se guarda como .R).
• Cerrar el script: Ctrl + W, o simplemente la "x" de la pestaña.
• Ejecutar una línea: pon el cursor en la línea y pulsa Ctrl + Enter.

2. Texto y ayuda (R base)

paste()
Une varios textos o valores en uno solo, separados por espacio (por defecto).
paste("El valor es", mi_valor)
# "El valor es 10"
paste0()
Igual que paste() pero sin espacio entre los elementos. Muy usado para construir nombres de archivo.
paste0("archivo_", "2024", ".csv")
# "archivo_2024.csv"
collapse =
Argumento de paste() / paste0() que junta TODOS los elementos de un vector en un solo texto, usando el separador que indiques.
mi_vector <- c("a", "b", "c")
paste(mi_vector, collapse = ", ")
# "a, b, c"
?funcion
Abre la ayuda oficial de una función (necesitas saber el nombre exacto).
?paste
??texto
Busca en TODA la documentación instalada cualquier función relacionada con esa palabra (útil si no recuerdas el nombre exacto).
??paste

3. Vectores y tipos de datos (R base)

c()
"Combine": crea un vector juntando varios valores.
mi_vector <- c(1, 2, 3, NA)
as.character() / as.double() / as.integer() / as.numeric()
Convierten un valor u objeto a texto, decimal, entero o número respectivamente.
as.character(123)   # "123"
as.numeric("123")   # 123
as.integer(4.9)     # 4
sum()
Suma todos los valores de un vector.
sum(mi_vector, na.rm = TRUE)
Igual que con mean(), si hay NA hay que añadir na.rm = TRUE.

ls()

5. Crear y explorar tablas (data.frame) (R base)

data.frame()
Crea una tabla nueva a partir de vectores (cada vector es una columna).
mi_tabla <- data.frame(
  nombre = c("Ana", "Luis"),
  edad   = c(25, 30)
)
rbind()
Añade una fila nueva a una tabla (o une dos tablas con las mismas columnas).
mi_tabla <- rbind(mi_tabla, data.frame(nombre = "Marta", edad = 40))
colnames() / rownames()
Muestran o cambian los nombres de columnas / filas.
colnames(mi_tabla)
colnames(mi_tabla) <- c("nombre", "edad_anios")
mi_tabla[fila, columna]
Selecciona partes de la tabla por posición. Si dejas un hueco vacío, coge TODO en esa dimensión.
mi_tabla[1, ]        # fila 1, todas las columnas
mi_tabla[ , 2]       # todas las filas, columna 2
mi_tabla[1, 2]      # fila 1, columna 2
mi_tabla$columna
Accede directamente a una columna por su nombre (devuelve un vector).
mi_tabla$columna
nrow() / ncol() / dim()
Número de filas, columnas, o ambos a la vez.
nrow(mi_tabla)  # nº de filas
ncol(mi_tabla)  # nº de columnas
dim(mi_tabla)   # c(filas, columnas)
names()
Igual que colnames() para data.frames; también funciona con listas.
names(mi_tabla)
unique()
Devuelve los valores distintos de un vector o columna, sin repetir.
unique(mi_tabla$columna)
factor()
Convierte una columna de texto en categorías (útil para variables tipo "sí/no", "bajo/medio/alto"...).
mi_tabla$columna <- factor(mi_tabla$columna)

Extras muy útiles para explorar una tabla

head(mi_tabla)     # primeras 6 filas
tail(mi_tabla)     # últimas 6 filas
str(mi_tabla)      # estructura: tipos de cada columna
summary(mi_tabla)  # resumen estadístico rápido
View(mi_tabla)     # abre la tabla en una pestaña visual

6. Borrar / añadir filas y columnas (R base)

Borrar una columna
Se asigna NULL a la columna, o se selecciona con un signo menos.
mi_tabla$columna <- NULL
# o, si usas número de columna:
mi_tabla <- mi_tabla[ , -2]
Borrar una fila
Igual, pero con el signo menos en la posición de la fila.
mi_tabla <- mi_tabla[-1, ]  # elimina la fila 1
Añadir una columna nueva
Se crea igual que si ya existiera.
mi_tabla$columna_nueva <- mi_tabla$edad * 2

7. Leer y guardar datos

R base
read.table() / read.csv()
Leen un archivo de texto/CSV y lo convierten en data.frame.
mi_tabla <- read.csv("datos.csv", sep = ",")
sep =
Argumento que indica el carácter que separa las columnas en el archivo (coma, punto y coma, tabulador...).
read.csv("datos.csv", sep = ";")
write.csv() / save()
write.csv() exporta una tabla a un archivo CSV. save() guarda cualquier objeto de R en formato .RData (para recuperarlo luego con load()).
write.csv(mi_tabla, "salida.csv", row.names = FALSE)
save(mi_tabla, file = "mi_tabla.RData")
readxl
library("readxl") + read_excel()
Lee archivos de Excel (.xlsx). sheet = indica qué pestaña leer.
library("readxl")
mi_tabla <- read_excel("datos.xlsx", sheet = "Hoja1")
haven
library("haven") + read_sav()
Lee archivos de SPSS (.sav).
library("haven")
mi_tabla <- read_sav("datos.sav")

8. Estadística básica (R base)

mean() / median()
Media y mediana de un vector o columna.
mean(mi_tabla$columna, na.rm = TRUE)
median(mi_tabla$columna, na.rm = TRUE)
quantile()
Calcula los cuartiles (o el percentil que pidas) de un vector.
quantile(mi_tabla$columna, na.rm = TRUE)
which()
Devuelve las POSICIONES donde se cumple una condición (no el valor, la posición).
which(mi_tabla$edad > 30)
# [1] 3 5   (filas 3 y 5 cumplen la condición)

9. Valores especiales y lógica (R base)

is.na() / !is.na()
Comprueba si un valor es NA (dato ausente). Con ! delante, comprueba lo contrario ("que NO sea NA").
is.na(mi_vector)
mi_vector[!is.na(mi_vector)]  # solo los valores que NO son NA
is.null() / is.nan() / is.infinite()
Comprueban si un objeto está "vacío" (NULL), si es un resultado matemático indefinido (NaN, ej. 0/0), o si es infinito.
is.null(mi_valor)
is.nan(0/0)
is.infinite(1/0)
any() / all()
any(): ¿al menos UNO cumple la condición? all(): ¿TODOS la cumplen?
any(is.na(mi_tabla))   # ¿hay algún NA en toda la tabla?
all(mi_tabla$edad > 0)
subset()
Filtra filas de una tabla según una condición (versión base de filter() de dplyr).
subset(mi_tabla, edad > 30)

10. Condicionales y funciones propias (R base)

if / else if / else
Ejecuta código solo si se cumple una condición.
if (mi_valor > 10) {
  print("Mayor que 10")
} else if (mi_valor == 10) {
  print("Es igual a 10")
} else {
  print("Menor que 10")
}
ifelse()
Versión "en una línea" del if/else, ideal para aplicar a una columna entera de golpe.
mi_tabla$categoria <- ifelse(mi_tabla$edad > 18, "adulto", "menor")
function()
Crea tu propia función reutilizable.
mi_funcion <- function(mi_valor) {
  return(mi_valor * 2)
}
mi_funcion(5)  # 10
suppressWarnings()
Ejecuta código sin que se muestren los mensajes de aviso (warnings) en pantalla.
suppressWarnings(as.numeric("abc"))

11. Bucles (loops) (R base)

for
Repite un bloque de código para cada elemento de un vector/rango.
for (i in 1:nrow(mi_tabla)) {
  print(mi_tabla$edad[i])
}
while
Repite el código MIENTRAS se cumpla una condición.
i <- 1
while (i <= 5) {
  print(i)
  i <- i + 1
}
repeat
Repite indefinidamente hasta que uses break para pararlo.
i <- 1
repeat {
  print(i)
  i <- i + 1
  if (i > 5) break
}
next / break
next salta a la siguiente vuelta del bucle sin terminar la actual. break corta el bucle por completo.
for (i in 1:5) {
  if (i == 3) next    # se salta el 3
  if (i == 5) break   # para antes del 5
  print(i)
}

12. Apply y sort (R base)

apply()
Aplica una función a todas las filas (MARGIN = 1) o columnas (MARGIN = 2) de una tabla, sin necesidad de un bucle for.
apply(mi_tabla, 2, mean, na.rm = TRUE)
# media de cada columna
sort()
Ordena un vector de menor a mayor (o al revés con decreasing = TRUE).
sort(mi_vector)
sort(mi_vector, decreasing = TRUE)

13. tidyverse / dplyr tidyverse

library("tidyverse")
Carga el paquete (en realidad, un conjunto de paquetes) que incluye dplyr, usado para manipular tablas de forma legible.
library("tidyverse")
select()
Elige columnas concretas de una tabla.
mi_tabla %>% select(nombre, edad)
filter()
Filtra filas según una condición (el equivalente moderno de subset()).
mi_tabla %>% filter(edad > 30)
arrange()
Ordena las filas según una o varias columnas. Añade desc() para orden descendente.
mi_tabla %>% arrange(edad)
mi_tabla %>% arrange(desc(edad))
distinct()
Elimina filas duplicadas (el equivalente de unique() pero para tablas enteras).
mi_tabla %>% distinct(columna)
group_by() + summarise()
Agrupa filas por una columna y luego calcula un resumen (media, suma...) para cada grupo. Son casi siempre pareja.
mi_tabla %>%
  group_by(categoria) %>%
  summarise(media_edad = mean(edad, na.rm = TRUE))
contains() / starts_with() / ends_with()
Se usan DENTRO de select() para elegir columnas por su nombre parcial.
mi_tabla %>% select(contains("edad"))
mi_tabla %>% select(starts_with("nom"))
mi_tabla %>% select(ends_with("_id"))
slice()
Selecciona filas por su número de posición.
mi_tabla %>% slice(1:5)   # las primeras 5 filas
Nota de ortografía: es summarise() (o summarize(), ambas funcionan), no "summarixe". Y es distinct con "t".

14. Operadores

%>% y |>
Los "pipes": toman lo de la izquierda y lo pasan como primer argumento a la función de la derecha. %>% viene de magrittr/tidyverse; |> es el pipe nativo de R (desde la versión 4.1), hacen básicamente lo mismo.
mi_tabla %>% filter(edad > 30)
# es equivalente a:
mi_tabla |> filter(edad > 30)
== / != / > / >= / < / <=
Operadores de comparación: igual, distinto, mayor, mayor o igual, menor, menor o igual. Siempre devuelven TRUE o FALSE.
mi_valor == 10   # ¿es igual a 10?
mi_valor != 10   # ¿es distinto de 10?
mi_valor >= 18
\n y \t
Caracteres especiales dentro de un texto: \n es un salto de línea, \t es una tabulación.
cat("Hola\nMundo")
# Hola
# Mundo
